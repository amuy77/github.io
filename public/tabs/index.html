    使い方

    Safariのタブをまとめて持ってくる
    1. Safariのタブ一覧を開いて、右上の ✓（選択）をタップ
    2. 残したいタブにチェック → チェックしたタブを長押し →「◯個のリンクをコピー」
    3. タブ置き場の ＋追加 →「コピーしたリンクを貼り付け」
    4. 入れる分類を選んで「追加」。済んだらSafariのタブは閉じてOK

    同じURLは自動でスキップ。分類は分けずに入れて、あとで「振り分け」でもOK。

    操作のコツ
    1. 項目をタップ → ページが開く
    2. 右にスワイプ → 済み（見終わった）
    3. 左にスワイプ → 削除（「元に戻す」で戻せる）
    4. … → 分類変更・メモ・ピン留め
    5. 未分類があると出る「振り分ける」で、1件ずつサクサク分類
    1タップ保存（ブックマークレット）

    見ているページを1タップで送れるブックマーク。タイトルも確実に入ります。

    1. 下の「コードをコピー」
    2. Safariでこのページを開き、共有 →「ブックマークを追加」→ 名前を「タブ置き場に送る」に
    3. 本のアイコン →「編集」→ そのブックマークのURL欄を消して、コードをペースト
    4. 残したいページで、本のアイコン →「タブ置き場に送る」

    バックアップ

    書き出し・読み込み

    データはこのiPhoneの中だけに保存されています。ホーム画面に追加して使うと消えにくくなります。ときどき「バックアップをコピー」して、メモアプリなどに貼っておくと安心。

    読み込み：バックアップの中身を貼るか、ファイルを選んでください。今のデータに足し合わせます。
