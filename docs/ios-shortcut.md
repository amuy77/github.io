# iPhone から LaRa にサッと送る

## 一番かんたん: 「リンクをコピー」→ アプリで「クリップボードから」

1. Instagram などで投稿の「…」→「リンクをコピー」
2. LaRa を開いて「＋」→「クリップボードから」
3. URL が入った状態でネタ帳のフォームが開くので、タイトルやメモを足して保存

Instagram はプレビュー画像を返してくれないので、投稿のスクショも「写真から選ぶ」で添えておくと後で見返しやすいです。

## 共有シートから直接送る（ショートカット）

iPhone の「ショートカット」アプリで 1 つ作ると、Safari や Instagram の共有シートに「LaRa に送る」が出ます。

1. ショートカット → 「＋」で新規作成 → 名前を「LaRa に送る」にする
2. 右上の「i」（詳細）→「共有シートに表示」をオン。受け取る種類は「URL」と「テキスト」だけにする
3. アクションを 2 つ追加する
   - **URL をエンコード**: 入力「ショートカットの入力」
   - **URL を開く**: `https://amuy77.github.io/github.io/#/add?text=` の後ろに、上でエンコードした結果を入れる
4. 完了

使うとき: 共有シート → 「LaRa に送る」→ Safari で LaRa が開き、ネタ帳のフォームに URL が入った状態になります。

### 注意

- ショートカットから開くのは **Safari** です。ホーム画面のアプリとは保存場所が別なので、Safari 側でも一度ログインしてください（一度やれば覚えます）。
- 保存したネタは同じアカウントのデータなので、ホーム画面のアプリにもすぐ反映されます。

## 手書きメモやレシピの紙を読み込む

1. 写真アプリで紙の写真を開く → 文字を長押し → 「すべてを選択」→「コピー」
2. LaRa → 図鑑「作る」→「テキスト」タブ → 「貼り付け」→「カードにする」

材料と手順に分かれたカードがすぐ出来ます（直しは手入力タブで）。写真そのものを AI に読ませたいときは「写真 → AI」タブへ。
